# 当前交互指南

Portal 先完成登录及私人搭档开通；加载失败可重试，不以空数据冒充成功。

| 分组 | 路由 | 使用方式 |
| --- | --- | --- |
| 我的搭档 | `/` | 查看档案、编辑职责/偏好、发起私人文本执行 |
| 任务协作 | `/automations`、`/automations/:id` | 日程目录、编辑、触发和真实执行历史 |
| 任务协作 | `/projects` | 项目目录及项目内看板、运行、审批、产物、背景、成员、动态 |
| 运行管理 | `/authorization`、`/usage` | 本人绑定渠道的脱敏配置及本人消耗 |

任务协作恰好包含「自动化」和「项目」。首页没有底部跳转快捷入口，不展示个人知识、技能、设备或独立执行历史菜单。

项目用 `/projects?project=ID&tab=board&task=TASK` 恢复空间与任务抽屉；运行详情为 `/projects/ID/runs/RUN`。可用 tab 是 `board`、`runs`、`approvals`、`artifacts`、`context`、`members`、`activity`。运行深链必须先授权，项目路径不匹配会报错。

旧工作台、任务列表、审批列表和个人历史列表路由转到项目目录。旧运行详情链接按实际授权来源定位到原项目或本人默认项目；自动化运行可返回真实来源日程。默认项目展示未归属运行时标为未关联任务，不虚构规划记录。历史会话深链仍受授权控制，不作为主导航入口。

“定义就绪”仅说明指令已编译。“模型未配置”需要管理员处理。授权页只表示已有绑定配置，不显示凭证或外部身份，也不证明 IM 已连通；企业渠道当前使用企业 Agent。网页是独立使用入口。

企业 `/tenant` 导航不含平台运营入口；平台 `/super-admin` 使用独立登录、身份与退出。项目任务提交与工具审批在各自上下文中操作，不能相互代替。产品范围与取舍见 [产品介绍](product.md)。
