# Portal 交互入口

Portal 需要有效企业成员会话和已开通的个人 Agent。导航为单层顶栏：

| 入口 | 路由 | 能力 |
| --- | --- | --- |
| 搭档档案 | `/` | 查看/编辑个人 Agent 档案，发起私人文本执行 |
| 成长 | `/growth` | 查看个人指令版本与执行记录 |
| 记忆 | `/memory` | 维护本人确认的文本记忆 |
| 技能 | `/skills` | 维护个人文本工作方法 |
| 知识 | `/knowledge` | 维护本人提供的背景知识 |
| 自动化 | `/automations` | 管理私人日程、手动触发和执行历史 |
| 项目 | `/projects` | 进入默认或共享项目及其协作视图 |
| 授权 | `/authorization` | 查看本人渠道授权投影 |
| 设备 | `/devices` | 查看并结束其他本人 Web 会话 |
| 消耗 | `/usage` | 查看本人使用统计 |

对话和企业已发布内容详情仍有路由，但不占据顶栏入口。没有单独的个人运行历史菜单；个人执行可从成长页面和本人默认项目关联记录进入。私人知识和记忆仅作为用户维护的文本上下文，不会触发自动采集。

项目空间通过 `/projects?project=ID&tab=board&task=TASK` 恢复项目、标签和任务抽屉；运行详情按真实项目归属授权。可用标签为 `board`、`runs`、`approvals`、`artifacts`、`context`、`members`、`activity`。旧工作台、任务列表和审批列表路由转到项目目录。

“定义就绪”表示私人指令已编译；模型未配置时执行仍会失败并提示管理员处理。授权页面展示已保存绑定，不证明外部渠道已经连通。企业后台 `/tenant` 和平台运营台 `/super-admin` 使用不同的访问授权；企业 Agent 不代表部门 Agent，部门归属尚未建模。产品边界见 [产品介绍](product.md)，数据与授权边界见 [系统架构](architecture.md)。
